# Kalorify • Personal Coach Edition

**Dein smarter, kostenloser KI-Ernährungscoach** – komplett offline-fähig und ohne Abo.

### Was Kalorify kann:
- KI-Coach, der deinen kompletten Tag kennt (Chat mit echtem Kontext)
- Automatisches Tracking per Nachricht („Ich habe 200g Hähnchen gegessen“ → wird automatisch eingetragen)
- Foto-Analyse von Tellern oder Nährwerttabellen (Claude / Gemini)
- Barcode-Scanner
- Open Food Facts + USDA + lokale Datenbank
- Favoriten, Rezepte, Manuell-Eintrag
- Gewichtsverlauf, Schritte, Wasser-Tracker, Streak
- Wunderschöne Dark & Light Themes
- Vollständig als PWA installierbar (funktioniert wie eine echte App)

**Kein Abo. Keine Werbung. Keine Cloud. Deine Daten bleiben bei dir.**

### So startest du:
1. App über den Link öffnen
2. Auf „Zum Home-Bildschirm hinzufügen“ klicken
3. Im Profil einen kostenlosen Claude- oder Groq-Key eintragen (optional, aber macht den Coach noch schlauer)
